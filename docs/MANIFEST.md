## 5. Cross-file contracts to preserve
- Swift enum raw values ⇔ Postgres enums (Enums.swift ⇔ migration).
- `AIModels.swift` field names ⇔ `schemas.ts` / `validation.ts` output.
- `SyncDTOs.swift` CodingKeys ⇔ SQL column names.
- Soft-delete property is `isSoftDeleted` in SwiftData (PersistentModel reserves `isDeleted`) and `is_deleted` in SQL.
