# StoreKit testing configuration (instructions)

File: THERMOAI/Resources/Configuration.storekit.md

A `.storekit` file is generated by Xcode (File › New › File › StoreKit Configuration File)
and must not be hand-written. Create `THERMOAI/Resources/Configuration.storekit` with:

| Group | Product ID | Type | Duration | Reference price |
|---|---|---|---|---|
| THERMO AI Pro | `com.example.thermoai.pro.monthly` | Auto-renewable | 1 month | 7.99 USD |
| THERMO AI Pro | `com.example.thermoai.pro.yearly` | Auto-renewable | 1 year | 49.99 USD, 1-week free trial |

Then: Scheme › Run › Options › StoreKit Configuration → select it.
Product IDs must match `PRO_MONTHLY_PRODUCT_ID` / `PRO_YEARLY_PRODUCT_ID` in Secrets.xcconfig
and the products created in App Store Connect.
